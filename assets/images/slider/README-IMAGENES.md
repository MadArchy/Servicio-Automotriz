# 📸 Imágenes del Slider

## Ubicación
Todas las imágenes del slider deben estar en esta carpeta:
```
assets/images/slider/
```

## Recomendaciones de Imágenes

- **Resolución recomendada:** 1920x1080 px (Full HD) o superior
- **Formato:** JPG o WebP (JPG funciona inmediatamente)
- **Tamaño:** Optimiza las imágenes para web (menos de 500KB cada una)
- **Aspecto:** Horizontal (16:9 o similar)

## Herramientas de Optimización

Puedes optimizar las imágenes usando:
- [Squoosh](https://squoosh.app/) - Optimización online gratuita
- [TinyPNG](https://tinypng.com/) - Comprime JPG
- [ImageOptim](https://imageoptim.com/) - Para Mac

## Verificación

Una vez que agregues las imágenes, verifica que:
- ✅ Los nombres coincidan exactamente (incluye mayúsculas/minúsculas)
- ✅ Las imágenes estén en formato JPG o WebP
- ✅ Los archivos estén directamente en `assets/images/slider/`
- ✅ No haya subcarpetas adicionales
